# Vision: optional distributed capability composition

ConnectorDome's immediate public mission is a useful, trustworthy, zero-cost, accountless connector builder and verifier. That mission does not depend on robotics, Consequential Formation, SymLan, ExoMCP, Anti-Illogical, or any BonAcqui system.

The long-range research hypothesis is narrower than “AI controls machines”: independently governed endpoints might be temporarily composed to perform a bounded task while each endpoint retains the right to refuse, stop, revoke, or report uncertainty. Robotics would then be a property of a qualified formation, not necessarily a permanent robot identity.

This repository currently demonstrates only software simulation. It does not establish safety, physical task success, economic advantage, or generality. Distributed physical actuation, safety-critical targets, and robotics orchestration are outside the immediate release scope.

Success for the open project means reproducible connector generation, verified portable output, useful examples, independent extensions, contributor participation, and honest evidence—not registration, telemetry, advertising, or lead capture.
