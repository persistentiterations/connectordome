# Distributed robotics roadmap

## Immediate release: Track A

- Keep the accountless read-only builder, verifier, registry, examples, and portable packages working.
- Improve installation, contributor documentation, reproducible receipts, and community adapters.
- Do not add advertising, mandatory telemetry, accounts, proprietary runtime dependencies, or upsells.

## Experimental alpha: Track B

- Completed: versioned schemas, extension API, local qualification, three-endpoint deterministic simulation, linked consequence receipts, and deliberate failure tests.
- Next: independent JSON Schema validation, replay fixtures, property/fuzz tests, adapter conformance kit, and benchmark harness.
- Later research: protocol adapters in simulation sandboxes and comparative trials against conventional arrangements.

## Exit gates before any physical pilot

Requires separate explicit authorization, threat model, device-specific hazard analysis, independent review, endpoint-local emergency behavior, hardware-in-the-loop evidence, rollback plan, and a narrowly bounded non-safety-critical target. Passing repository tests does not satisfy these gates.

## Comparative evidence

Declare the task and baseline before testing. Measure task completion, latency, reliability, integration labor, coordination traffic, energy, recovery, and refusal behavior. Publish failures. If overhead or risk erases the claimed benefit, record HOLD or reject the hypothesis.
