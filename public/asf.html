What is ASF?

ASF is APTD Sensor Fabric: a read-only observation interoperability standard. ConnectorDome does not create a new ASF. You create ASF connectors.

A connector maps a source (API, simulator, text claim, later a local device) onto a ReceptorEvent. Observation never implies authority.

ONE INTERFACE TO OBSERVE.
NO INTERFACE TO BLINDLY OBEY.
