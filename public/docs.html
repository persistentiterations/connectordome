Research lineage

ASF and ConnectorDome emerged from the Fractalish research program on persistent, provenance-bearing machine observation and governed transition. That is background, not a prerequisite.

fractalish.com

Open ecosystem

ConnectorDome is independently useful. Its Apache-2.0, versioned interfaces are intended to support third-party adapters, validators, reasoning modules and monitors without permission, registration, advertising or mandatory telemetry.

  • Ecosystem status and extension interface
  • Experimental architecture review — software simulation only
  • ExoMCP — separate public project; no functioning integration
  • Anti-Illogical — separate public project; no functioning integration
  • SymLan — planned interoperability concept; no public ConnectorDome integration

Fractalish is research lineage, not a runtime dependency. Physical actuation and distributed robotics orchestration are outside the immediate release scope.

ConnectorDome is an open-source project stewarded by BonAcqui LLC.
