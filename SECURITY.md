# Security Policy

Report vulnerabilities to **security@connectordome.com**.

Please include enough detail to reproduce. Prefer a private report before public disclosure.

We are especially interested in:

- SSRF bypasses
- secret leakage
- sandbox escapes
- mutating-operation exposure
- package substitution
- provenance spoofing
- registry integrity defects

There is no bug bounty and no promised response SLA.

Do not use security@ for general support. Use hello@connectordome.com.

ConnectorDome v0.1 is observation-only. A report that a connector can actuate hardware is in-scope.
